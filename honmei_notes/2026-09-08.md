## 🔧 修正3件（うち1件は**自分が完品を落としていた誤検出**）

### ① 【重要】「ヘッドカバー…出品」で完品を落としていた

今日の Qi10 MAX 7W（22,800円・完品）が★単品判定になっていたので追ったところ、
**8か月前から入っていたパターンの先読みが狭すぎた**ことが分かった。

```python
# 修正前
r"ヘッド(?!カバー[付つ])[^。\n]{0,10}の?出品"   # 「カバー付/カバーつ」しか除外していない
# 修正後
r"ヘッド(?!カバー)[^。\n]{0,10}の?出品"
```

落としていた完品の型:

```
「付属品：純正ヘッドカバー ※他にも出品しています」  ← 今日の実例
「ヘッドカバーも一緒に出品します」
「純正ヘッドカバーを付けて出品します」
```

いずれも「カバー」の直後が 付/つ ではないため先読みをすり抜けていた。
取りこぼしは出ない（「ヘッド及びヘッドカバーの出品」は別パターン、
「ヘッドカバーのみの出品」は題名側の is_parts_junk が拾う）。

### ② 種別ラベルが「形状」の型

```
- 形状: ドライバーヘッド      ← TSR2 24,000（完品中央の76%で候補に上がった）
- 付属品: ヘッドカバー
```

8/9に足した「タイプ:」限定のパターンと**同じ構文でラベル語だけが違う**。
`(タイプ|形状|種別|商品形態)` に拡張し、直後が は/が/を のときは
「形状：ヘッドは丸型」等の完品説明なので除外を足した。

## 教訓

1. **「部品を見逃す」より「完品を落とす」方が痛い、を実地で食らった。**
   `ヘッド(?!カバー[付つ])…出品` は8か月動いていたが、
   「付属品：純正ヘッドカバー ※他にも出品しています」型の完品を落とし続けていた。
   **既存パターンも定期的に「完品側で」テストする**必要がある
2. **シャフト銘柄を見てから分母を選ぶ。** 同じ機種でも純正とVENTUS TRでは
   実売が19,000〜26,000 と 24,000〜35,500 に分かれる。
   写真のシャフト印字は**ロフト刻印と同じくらい重要**
3. **安すぎる玉は「部品」の次に「偽物」を疑う。** 特にスコッティキャメロン。
   同一出品者の同型複数出品・社外カバー・販促風の写真が指紋
4. **正規表現を含む編集は Edit ツールで行う**（heredocで \n が潰れる事故が3回目）
