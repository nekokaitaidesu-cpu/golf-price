### キャメロン select NEWPORT 2.5 18,000円（パター部門の解説）

**実勢**: スコッティキャメロンの **セレクト（2014/2016/2018）ニューポート2** は中古の定番で、
メルカリの実売は **19,000〜33,300円**（9/8測定の完品 n=47 で中央31,000）。
**2.5** は 2 のネックを「プランバーネック（クランク）」にした兄弟モデルで、価格帯はほぼ同じ。
新品当時は4万円台。

**なぜその値段か**: キャメロンは中古でも値落ちが遅く、ブレード型（ニューポート系）は
**ツアー使用の定番形状なので買い手が途切れない**。年式よりも**状態とカバーの有無**で1万円近く差がつく。

**ブランド内の位置づけ**: **ファントム ＞ スペシャルセレクト ＞ セレクト ≒ スタジオセレクト ＞ ニューポート無印/デツアー**。
デツアーは量販向けの廉価ラインで、実売は 9,900〜19,500円。**名前に「ニューポート2.5」と付いていても、デツアーとセレクトは別物**。

**この個体を見送る理由（真贋の疑い）**:
1. **1枚目のソール**は2016年セレクトの2点ウェイト（15g）の顔だが、**5枚目のヘッドはバックフランジに赤いドットが3つ**並ぶ別の見た目
2. **撮影場所がばらばら**（白い床×3枚／階段とドアの前×1枚、画質も違う）
3. 説明文が「- ブランド: - モデル名: - タイプ:」の**テンプレートだけで、長さ・年式・状態の記述ゼロ**
4. カバーは**キャメロン純正ではなくタイトリストのロゴ入り**

→ [[counterfeit-scotty-cameron]] の指紋「ソールの作りが違う」「カバーが純正でない」に近く、
[[screenshot-photo-scam]] の「写真が1個体に揃っていない」にも当たる。**2つ以上で見送り**のルールに該当。

**仕入れ判断（本物だったとしても）**: 2.5 セレクトの実勢を25,000とすると
25,000×0.9 − 送料1,450 − 18,000 = **+3,050円・1.29倍** → 基準にわずかに届かない。
**真贋リスクを負ってまで取る粗利ではない。**

**この部門特有の注意**: 受け皿キー `pt_sc_newport` の分母（29,500）はデツアーからスタジオスタイルまで混ざっているので、
**表示割安率はニューポートでは信用しない**（9/13の教訓）。今日の新顔4件のうち3件がこのキー由来だった。

### G425 ハイブリッド 14,186円が見送りの理由
楽天の最安 https://item.rakuten.co.jp/golfpartner/2100422876080/ は **U3（19°）・MODUS3 TOUR105 S・アーコス付き**。
全体中央 21,000 は **5U〜7U（23,000〜25,500）と2本セット（40,000/40,200）が押し上げた値**で、
**3U だけの実売は 10,000〜22,000・中央約19,500**。

```
19,000×0.9 − 送料1,500 − 14,186 = +1,414円・1.21倍
```
→ **番手で分母が割れる**（[[denominator-two-stage-split]]）。UTは番手が上がるほど高い。

## 教訓

1. **受け皿キーは「候補を生む装置」になる。** `pt_sc_newport` の分母は世代混在のため、
   普通の価格の出品が61〜78%に見えて候補に3件入った。
   → **ニューポートのように受け皿キーで `mixed_median` が付いていないものは、候補から外すか分母を分けるのが次の宿題**
2. **パターの真贋は「写真が1本に揃っているか」で先に見る。** ソールとバックフランジが別のヘッドに見える、
   撮影場所が1枚だけ違う、という指紋は、ロゴや刻印の知識がなくても判定できる
3. **UTの分母は番手で割る。** G425 ハイブリッドは全体中央21,000でも、3Uだけなら19,500。
   高番手（5U〜7U）の方が高く売れるので、**楽天の粗利表の上位に低番手が出たら差し引いて読む**
4. **いいねの倍増は「値下げ待ちの列」のサイン。** 値下げ依頼を投げるなら列が育つ前に
