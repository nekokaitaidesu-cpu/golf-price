```

```

ドライバーの凹みは性能・耐久性に関わるので減点が大きく、さらにカバー無し。
完品中央24,000に対し、凹み＋カバー無しの現実線は19,000〜21,000。

**注意点として記録**: 17,000という価格は**ヘッド単品の実売帯（10,000〜18,000）と
完全に重なっている**。この機種は「割安な完品」と「普通のヘッド単品」が
同じ価格帯に並ぶので、毎回説明文と写真の確認が要る。

| | 書き方 | 例 |

## 教訓

1. **「分母が正常でも買えない」ケースが今日は2件**。分母検査は必要条件であって
   十分条件ではない。**分母→説明文→写真**の3段は変わらず全部要る
2. **モデル番号が細かいブランドは、番号ごとに実売n=1〜4しかない**。
   キャメロンのファントムは13種類の番号が並んで、n≥3は 7.5 / 5S / 5.2 の3つだけ。
   → **n<3の番号は「相場が無い」と扱う**のが正しい
3. **穴は「安全に取れる分」と「取れない分」を分けて、取れる分だけ取る**。
   今日のシャフト71件は、11件だけ回収して60件は条件をコメントに書いて保留した。
   全部取ろうとして誤検出を出すより良い
