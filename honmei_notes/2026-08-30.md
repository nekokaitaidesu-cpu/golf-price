## 🔧 楽天の偽の粗利 +1,840 を止めた（Qi10 レスキュー）＋カタログ分割

朝の楽天照合で最大だった `テーラーメイド Qi10 レスキュー`。分母検査をかけた。

```
ut_tm_qi10  120日実売59件  範囲 5,000〜48,000 = 9.6倍
  （記載なし=無印） n=32 中央 20,300
  max              n=25 中央 25,000
  tour             n= 2 中央 35,300
  全体中央 23,800 ← どちらでもない中間値
```

楽天の玉は「**Qi10 レスキュー U3 Diamana Blue TM60**」= **無印**。

| 使う分母 | 粗利 |
|---|---|
| 全体中央 23,800（誤） | **+1,840** |
| 無印中央 20,300（正） | **−1,310 赤字** |

### 原因は「UTだけ excludes が空だった」

```
tm_qi10     (driver) excludes ["max","ls"]  ← 分けてある
fw_tm_qi10  (fw)     excludes ["max"]       ← 分けてある
ut_tm_qi10  (ut)     excludes []            ← ここだけ取り残されていた
```

無印 n=32・MAX n=25 と**両層とも母数が十分**なので、mixed_median ではなく
**分割**で対処（8/22スパイダーと同型）。`ut_tm_qi10max` を新設。

```
分割後  無印 30日27本・中央20,300・7日2本・回転6.6日・販売中32
        MAX  30日18本・中央25,900・7日3本・回転4.2日・販売中44
検証    find_duplicates()=0 ／ find_swallowing() は既知の4対のみで増減なし
```

副次効果として、候補に上がっていた **Qi10 TOUR レスキュー 19,000（80%）が候補外**になった
（無印中央20,300に対して94%）。

### ⚠ 一般則の更新: 混在は「年式」だけでなく「**同年式のグレード**」でも起きる

| 日 | 機種 | 混在の軸 |
|---|---|---|
| 8/27 | プロギア RS | 年式（2016〜2024） |
| 8/28 | オノフ KURO | 年式（2019〜2026） |

8/28に「国内メーカーは同名で年式更新する」と書いたが、**海外勢は同年式内で
無印/MAX/LS/TOURに枝分かれする**という裏返しの穴がある。
→ **ドライバーで分けてあるグレードは、FW・UT・ショートウッドでも分かれているか棚卸しする**。
今回は driver と fw が済んでいて ut だけ漏れていた＝**カテゴリ横断の抜けが本体**。

### この機種の値段の理由（相場に不案内な部門なので補足）

- **スパイダー ツアーXは現行ツアー系の上位**。定価は5万円台で、中古の実勢は

  値段は倍ほど違うので、出品タイトルの「ツアーX」の有無で分母を切り替えること

## 教訓

1. **🔴警告が出た機種では、写真より先に「出品価格 ÷ ヘッド単品中央」を計算する**。
   8/28も8/30も、この比が1.0前後だった時点で結論は出ていた。写真は確認であって発見ではない
2. **カテゴリ横断で棚卸しする**。Qi10 レスキューの穴は「見落とし」ではなく
   「driver と fw は直したが ut を直し忘れた」という**作業の抜け**。

   excludes を突き合わせる**のが正しい直し方
3. **割安率は分母を3回疑う**。今日の G425 MAX FW は
   ①ヘッド単品混入21% ②番手混在（3W真値18,000 vs 表示20,000）の**二重**だった
4. **パターはネック形状まで見ないと分母が出ない**。ブランド → ライン → 世代 → **ネック**
   と4段階ある。8/22の分割はまだ1段浅かった
