2026-09-23発見。ELYTE 7W の出品「美品 ELYTE 7w 21 度 フェアウェイ Callaway」は
`_catalog_match` が True なのに、部門レポートの検索キーワード
`キャロウェイ ELYTE フェアウェイウッド` では**取得できなかった**（「キャロウェイ」も「フェアウェイウッド」も題名に無い）。

**実測（30日・4機種）**: 正式キーワードのみ 8/12/23/18件 → 「◯◯ 7W」「◯◯ 9W」の短縮を足すと 16/32/48/46件。
**見えていたのは35〜40%**。しかも**題名が短い個人出品ほど漏れる＝安い玉ほど見えない**。
9/18に Qi10 7W 15,800円（1.73倍）を取りこぼした原因もこれ（[[thin-category-blind-spot]]）。

**対処（`scripts/shortwood_report.py` に実装済み）**: `short_queries()` で「モデル名＋番手」を作り、
`_search_union()` で item id の和集合を取る。ただし短縮クエリは**シャフト単品を大量に連れてくる**ので
`_looks_like_shaft()` で落とす（「7W用」「(60S)用」「シャフトのみ」、および
「シャフト」を含み装着語もクラブ情報も無いもの）。
⚠ 「シャフト」だけで落とすと**「純正シャフト付き」の完品**を巻き込む。反例13件のテストで確認すること。

**How to apply:** 「販売中0件＝品薄」と読む前に検索が届いているか疑う。
**部門表の中央値と広く引いた中央値が食い違ったら広い方を信じる**
（PARADYM 7W: 部門表15,500 n=5 vs `flea_comps.py "PARADYM 7W"` で24,656 n=104）。
同じ穴は `popularity`（クラウド集計）にも残っている＝**ミニドラ・ウェッジ・パター部門も未対応**。
