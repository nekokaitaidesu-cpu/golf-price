楽天の仕入れ候補を推奨する前に、**商品ページの「商品詳細 → 種別」欄**を必ず開く。
題名にも検索APIの返り値にも出てこないが、ページには
「種別: ヘッド単品 / ユーティリティ / ドライバー…」がそのまま書いてある。

**Why:** ピン G410 ハイブリッド U4 10,450円（ゴルフエース3号店）を
**2026-09-04 と 09-10 の2回**「シャフト・フレックス・長さが全部『-』＝情報不足だが
1.76倍」として推奨しかけた。ユーザーが現物を確認して「ヘッドのみだねー」と指摘。
ページには **種別=ヘッド単品・重量246g** と書いてあった。
**『-』は情報が無いのではなく、該当する部品が存在しないという意味**だった。
完品の分母（4U中央21,000）で割ったので1.76倍という幻の数字が出ていた。

**How to apply:** `scripts/rakuten_spot.py` が安い順5件について 種別/重量 を
自動で引くようにした（2026-09-11・commit 21366e1a）。🔴が出たら
[[which-denominator-not-whether]] に従ってヘッド側の分母に切り替える。
重量も裏取りに使える: **ヘッド単体は DR約200g・FW/UT約240g、完品は約370g**。
題名側の「モデル名 - 番手」型（シャフト欄が空のまま連結された形）は
679件中2件しか出ず真陽性n=2と根拠が薄いので、フィルタには使わない。
