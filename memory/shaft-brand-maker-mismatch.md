出品の説明文に書かれたシャフト名は、**写真の刻印メーカーと必ず突き合わせる**。
ブランドとメーカーは1対1で決まっているので、食い違えば説明文が嘘だと即断できる。

- **VENTUS / SPEEDER / MOTORE** = フジクラ
- **TENSEI / Diamana / KURO KAGE** = 三菱ケミカル
- **HZRDUS / Smoke / RDX** = トゥルーテンパー（Project X）
- **ATTAS** = UST Mamiya ／ **Tour AD** = グラファイトデザイン

**Why:** 2026-09-26、SIM2 MAX 4UT 14,900円（割安率80%）の説明文が
「シャフトUS純正 ventus blue UT 6R」だったが、シャフト接写の刻印は
**MITSUBISHI CHEMICAL / TM 4◯ / FLEX-L**。VENTUSはフジクラ製なので三菱の刻印は
あり得ず、実物は純正TENSEI TMの**Lフレックス（レディース）**だった。
部品検出でもクラック検出でもない**新しい型のすり抜け**で、
スペックを信じたまま買うと出口で必ず揉める。

**How to apply:** シャフト名が価格の根拠になっている出品（「VENTUS付き」「Tour AD」など
カスタムを売りにした玉）は、**刻印の接写があるかを先に見る**。無ければ社外シャフトの
価値をゼロとして値付けする。刻印が読めたらメーカー名を上の対応表と照合する。
フレックス表記（FLEX-L / R / S / X）も同時に読めるので、説明文の「6R」等と突き合わせる。
