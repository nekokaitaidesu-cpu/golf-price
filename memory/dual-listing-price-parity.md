2026-08-31、KING TEC-MD が **ヤフー57,800／メルカリ55,000** の二正面出品で
**先にメルカリが売れ、8,300円を取りこぼした**。

```
メルカリ 55,000 → 55,000×0.9 − 送料1,700 = 47,800 → 利益 +7,025
ヤフー   57,800 → 57,800    − 送料1,700 = 56,100 → 利益 +15,325
```

同じ日に売れた GT280 は **ヤフー37,000／メルカリ41,000** で手取り 35,300 と 35,200＝**差100円**。
どちらが売れても同じだった。**差が出たのは値付けの揃え方だけ**。

**Why:** 二正面は「どちらが先に売れるか選べない」。手取りが揃っていないと、
**安い側が先に売れるリスクをそのまま抱える**ことになる。
ヤフーフリマは手数料0%（〜2026-10-11）、メルカリは10%なので、
同じ表示価格だと手取りが1割違う。

**How to apply:** 送料が同じなら **メルカリ価格 = ヤフー価格 ÷ 0.9**。

| ヤフー | あるべきメルカリ |
|---|---|
| 15,800 | 17,600 |
| 26,800 | 29,800 |
| 29,800 | 33,100 |
| 45,800 | 50,900 |
| 57,800 | 64,200 |

出品キットを作るときは**必ずこの検算を入れる**。片方が売れたら即もう片方を取り下げる、
という運用とセットで初めて成立する。0%キャンペーンが終わったら係数を見直すこと
（メルカリ10%・ヤフー5%なら メルカリ価格 = ヤフー価格 × 0.95 ÷ 0.9）。
