2026-09-01、Qi4D ドライバー 35,000円（**1.0時間前の新着・割安率56%・表示粗利+19,550**）
という全条件がそろって見える玉が出た。**見送った理由は価格でも傷でもなく「分母が無い」こと**。

```
dr_tm_qi4d  120日実売16件  範囲 58,000〜67,000  最大/最小 = 1.2倍（極端にタイト）
出品価格 35,000 = 完品中央62,500の56%・ヘッド単品中央60,000の58%
説明文「訳あり クラウン部分に剥がれがあり安く出品します」
写真4枚目: クラウンのトゥ寄りに斜めの線状の割れ／剥がれ（長さはクラウンの約1/3）
```

**実売16件のうち、剥がれ品は0件。** つまり「クラウンが割れたQi4Dがいくらで売れるか」の
実績が存在しない。健全品の58,000〜67,000というレンジは出口価格に使えない。

**Why:** 割安率は「健全品の中央値」で割った数字なので、**状態が実売サンプルに無い種類の
瑕疵**だと、計算できているように見えて実は何も計算していない。
加えてカーボンクラウンの線状の割れは、塗装剥がれと違って**強度不安**を持たれるため、
値段以前に売れない可能性がある（構えたときに見える位置でもある）。

**How to apply:** 「訳あり」「難あり」「ジャンク」表記の玉を見たら、
**同じ種類の瑕疵を持つ個体が過去に売れているか**を先に検索する。
- 実績があれば、その価格帯を分母にして判断する
- **実績が0件なら見送る**。掘り出し物ではなく「値付けできない物」

CLAUDE.md の「回転（7日売れ数）のない粗利は罠」の変形＝**分母のない割安も罠**。
