タイトルにヘッドの語を入れず、説明文だけで単品と分かる出品者が複数いる。
**文末の定型文が指紋になる**ので、見つけたら記録して次回すぐ判別する。

## 常連①「名器！」出品者（実績4件）
タイトル冒頭に「名器！」「【名器】」を付けるヘッド単品専門業者。
一次トリアージの段階で落とす。

## 常連②「-シャフト無し」＋NCNR定型文（2026-09-01／09-02で連投を確認）

```
9/01  Qi10 ドライバー 24,444（ヘッド単品中央21,000の116%）
9/02  SIM2 ドライバー 17,000（ヘッド単品中央16,000の106%）
```

書式が3点そろって一致する:
1. タイトルは「◯◯ ドライバー ロフト」だけで**ヘッドの語を入れない**
2. 説明文のスペック欄に「**-シャフト無し**」を**1行だけ**入れる
3. 文末が「**質問等あれば気軽にお聴き下さい。即購入OK トラブル防止のためNCNRで
   お願いします。ご覧いただきありがとうございます。**」で完全一致

**価格は必ずヘッド単品中央のすぐ上**（116% / 106%）＝**割安ですらない**。

**How to apply:** この書式を見たら、割安率を出す前に**分母をヘッド単品側に切り替える**。
完品中央で割ると60〜70%台の「割安」に見えてしまう（Qi10は63%、SIM2は71%と表示された）。

なお「-シャフト無し」は 2026-09-01 に `detect_head_only_desc` へ追加済みで、
**翌日のSIM2で自動検出が効いた**。すり抜けを見つけたらその日のうちに足す価値がある。

## 指紋③「ヘッド重量◯g」だけ書いてシャフトに触れない（2026-09-15）

GT2 9° 35,000（出品126件）。説明文は「後方ウェイト7g」「**ヘッド重量は193g**」「すり替え防止のため返品不可」だけ。
写真でホーゼルが空いていた。**完品を売る人はクラブ総重量か長さを書く**ので、
ヘッド重量だけ書いてあったらヘッド単品を疑う。9/13 の Qi10 ヘッド（「重さ：195g」）も同じ書き方だった。
