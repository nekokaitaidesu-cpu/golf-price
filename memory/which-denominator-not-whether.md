無言のヘッド単品を6件見て、扱いが2つに分かれることが分かった（2026-09-03）。

| 出品価格 ÷ **ヘッド単品中央** | 意味 | 対応 |
|---|---|---|
| **0.9〜1.1** | 出品者がヘッド相場を見て正直に付けている | **見送り**（ヘッド単品としても割安でない） |
| **0.9未満** | ヘッド相場より下 | **ヘッド単品の分母で買えるか計算する** |
| 1.1超 | 完品と誤認させる値付け | 見送り |

## 実例

**見送った4件（比 0.9〜1.1）**
```
8/28 G440 MAX  48,000 ÷ 48,100 = 1.00
8/30 G425 LST  17,000 ÷ 16,500 = 1.03
9/01 Qi10 DR   24,444 ÷ 21,000 = 1.16
9/02 SIM2 DR   17,000 ÷ 16,000 = 1.06
```

**買えると判定した1件（比 0.64）**
```
9/03 ROGUE ST MAX LS  9,100 ÷ 14,300 = 0.64（🔨オークション開始価格）
     ヘッド単品中央14,300・送料510 → ヤフー0%手取り上限 13,790
     買い上限 = 13,790 ÷ 1.30 = 10,600円
```

**Why:** 5件連続で見送っていたため「ヘッド単品＝敵」になりかけていた。
実際は**分母を完品からヘッド単品に切り替えれば、普通の仕入れ判断**になる。
オークションは開始価格が相場を大きく下回るので、この形が出やすい。

**How to apply:** 説明文・写真でヘッド単品と分かったら、そこで止めずに
**ヘッド単品中央で割り直す**。0.9未満なら
「ヘッド単品中央 − ヘッド送料510」を手取り上限として 1.30倍の買い上限を出す。
オークションなら**その上限で機械的に入札し、超えたら降りる**。
