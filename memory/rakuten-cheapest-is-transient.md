**楽天→メルカリ粗利ランキングの最安（used_min）は、その場に無いか、すぐ無くなる。**
中古ショップの1点物なので、売れるとページごと消える（在庫0の表示が残らない）。
消え方には2種類あり、対処が違う。

**A型「インデックスの幽霊」** — もう無いものが何日も表に出続ける
- 2026-09-24 プロギア RS-F 5,850 → 照合したら消滅済み・実勢10,080（GDO）
- 2026-09-26 ボーケイ SM10 6,760 → 消滅済み・実勢9,707。しかも54°/56°で58度ですらない。
  **9日連続で空振り**した末、9/27にランキングから自然に落ちた
- 対処: 空振り回数をメモに書いて放置してよい。**手で除外リストを育てるより安い**

**B型「本物がその日のうちに売れる」** — 照合時点では実在する
- 2026-09-27 ピン G425 MAX 9°【訳あり】Cランク 12,580（ゴルフドゥ）。
  05:02のスナップショットから約18時間生存 → **22:02の照合時は実在 → 1時間以内に消滅**。
  次に安い玉が18,040で差が5,460円あり、見つけた人がすぐ動いた
- 対処: **照合・現物確認・購入判断を同じ時間内に済ませる。**「明日ページを開いて訳ありの
  中身を確認する」は間に合わない

**Why:** B型を翌日回しにして1件逃した（2026-09-27）。ユーザー報告「G425はページが削除されていたね」。
ライブ照合の目的は「在るかどうか」の確認であって、**在ると分かった時点が判断の期限**。

**How to apply:**
- ランキング上位を `rakuten_spot` で照合し、**在った玉は1.30倍を満たすならその場で決める**
- 判断に現物情報（訳ありの中身・Cランクの程度・種別欄）が要るなら、**照合と同じセッションで
  商品ページまで開く**（[[rakuten-shubetsu-field]]）
- 消えた玉は翌日 `rakuten_spot` で再確認する。**同スペックが価格を直して戻っていれば誤登録、
  戻らなければ売れた**
- 逆に、1.30倍を満たさない玉は消えても追わない。G425 MAXは訳あり・Cランク・45.0インチ
  （標準45.75インチ＝カット疑い）の3点セットで、中身次第では見送りだった
