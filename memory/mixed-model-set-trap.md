**アイアン等のセット出品は、本数が合っていても中身が同一モデルとは限らない。**
スキャンは**題名に出てくるモデル名**で分母を決めるので、
新しいモデル名が1本ぶんでも入っていると、**セット全体がその分母で評価されて割安に見える**。

**Why:** 2026-10-06、「テーラーメイド ステルス　ロケットブレイズ アイアン　セット　6本 5〜P S」
35,000円が **割安率78%** で候補に出た。説明文を読むと:
```
■5番       : STEALTH（2022年）           KBS 85 S          ← 1本だけ
■6〜PW(5本) : ROCKETBLADEZ（2012年）      ROCKETFUEL LIGHT  ← 10年前のモデル
```
ロケットブレイズ6本セットの120日実売は **n=8 中央 20,800**。
実体価値はステルス5番を足しても24,000前後で、**35,000は明確に割高**だった。
候補リストの78%は「ステルスアイアン（約45,000）」の分母で出たもの。

**How to apply:**
- セット物は「本数が中央値の基準（6本フル）と合うか」（CLAUDE.md）に加えて、
  **説明文の番手ごとの記載を読んで、全部同じモデルかを確認する**
- 混成だった場合は**多数派のモデルで分母を取り直す**（上の例ならロケットブレイズ6本の20,800）
- 題名に2つのモデル名が並んでいたら、それ自体が混成のサイン
- シャフトが番手で違う（5番だけKBS、他はROCKETFUEL）のも手掛かり
