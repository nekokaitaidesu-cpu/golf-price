2026-08-22新設（ユーザー指示「値持ちする人気モデルに絞る」「送料に負けない価格帯」）。
ウェッジ8機種／パター17機種。`category="wedge"` / `"putter"`。

**採用基準: 90日実売の中央が10,000円以上 かつ 実売8本以上。**
送料1,450＋手数料10%を引いて粗利が残る下限がここ。数は出るが不採用にしたもの:
ボーケイSM8(23本/8,000)・JAWS RAW(17本/8,000)・RM-4(16本/7,100)・
RTX ZipCore(13本/7,500)・Glide4.0(13本/8,800)・ミズノT24(9本/8,000)。
→ **ユーザーが「薄利でもいいから拾いたい」と言ったらこの次点群を足す**。

  MG4 17本/11,900・JAWS MD5 14本/10,740・OPUS 13本/10,000・MG3 12本/13,600

**Why（この部門特有の罠）:**
- **パターはヘッドカバー単品それ自体が2,000〜25,000円で売買される**（キャメロンの
  限定カバーは18,800円で実売）。スペシャルセレクトは実売20件中12件がカバーで、
  中央値が **4,250円 → 28,250円**（6.6倍）ずれていた
- 逆に `_JUNK_TOKENS` の **"ネック"** が「ツイストネック/クランクネック/
  スラントネック/溶接ネック」という**パターの標準的な形状名**を落としていた。
  実測1,651件中「ネック」を含む9件は**全部完品**（7,500〜222,000円）
  → **新部門を足すときは、既存のJUNKトークンがその分野の専門用語と衝突しないか実測する**

**ウェッジはロフト別に測る**（2026-09-11実測）。部門の中央値はロフト混在で、
楽天の安い個体は**弱いロフト（54/56度）に偏る**。ボーケイSM10 完品n=68・中央15,350の内訳:
50度 14,000(n=14) / 52度 15,500(n=9) / 56度 12,500(n=4) / **58度 16,500(n=7・15,000〜18,500と幅が狭い)** / 60度 19,000(n=2)。
**58度がいちばん値持ちして読みやすい**。バウンスでも別商品になる。

**パターのライン違いは題名の表記ゆれで隣に落ちる**（2026-09-11）。
「SCOTTY CAMERON パターファントム**12.5**」は題名にXが無いため無印ファントム
（中央46,900）に吸われ、64%＝割安圏の偽陽性になっていた。12.5の実売16件は全て
ファントムX（中央28,000）で、実際は106%＝相場超え。→ catalog で
`ファントム125|phantom125` を無印のexcludesとX側のrequiredに追加済み。
⚠ **5.5 / 7.5 / 12 は無印にも実在する**ので番号での切り分けは12.5だけに限ること。

- **残課題**: `pt_tm_spidertour`（無印）は分割後もまだ 8,000〜46,000 と広い。
  下位クラスタ(2017 RED/BLACK)と上位(TM1/TM2トラス)が残っているので、
  ここの割安候補は検死で世代を確認すること

  実売1〜3本と薄い。**「実売ゼロ＝品薄」と読まない**（[[flip-inventory]] の8/18の教訓）
