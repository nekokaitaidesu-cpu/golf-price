**部品検出のパターンを足すときは `desc_corpus.py diff` だけで判断しない。
必ず自分で「完品ならこう書く」反例を3〜5本書いて通す。**

**Why:** 2026-09-07、ヘッド単品用に検討した
`r"ヘッドと[^。\n]{0,25}ヘッドカバーが(付属|付き)"` は
**完品コーパス96件で誤検出0件**だったが、自作の

> 「ヘッドとシャフトの状態は良好、ヘッドカバーが付属します。」← 完品

を落とした。採用していれば完品を静かに捨て続けていた。
コーパスは96件しかなく、しかも [[thin-denominator-fake-cheap]] と同じで
**中身が4件汚染されている**（9/6発見・シャフト単品混入）。
CLAUDE.md の「完品を落とす方が痛い」を守るには母数が足りない。

**How to apply:**
- 手順: ①`desc_corpus.py diff "<新パターン>"` が0件 →
  ②**自作の完品文で False になる**ことを確認 → ③両方通ったら採用
- 反例は「その語が完品の文脈で自然に出る形」を狙って書く
  （「中古ヘッドカバー付き」「装着シャフト:◯◯」「〜を装着しています」など）
- 不採用にしたパターンは**理由付きでコードのコメントに残す**（再発明を防ぐ）
- 採用時は否定先読みで逃がす手が有効（例 `中古ヘッド(?!カバー)`）
