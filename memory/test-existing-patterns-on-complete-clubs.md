**部品検出パターンは足すときだけでなく、既に動いているものも
「完品を落としていないか」で定期的に測る。**

**Why:** 2026-09-08、`_HEAD_ONLY_DESC_PAT` の
`r"ヘッド(?!カバー[付つ])[^。\n]{0,10}の?出品"` が、**8か月動いた末に**
完品を落としていたことが分かった。先読みが「カバー付/カバーつ」しか
除外しておらず、次の型が全部すり抜けていた。

```
「付属品：純正ヘッドカバー ※他にも出品しています」← 完品のQi10 MAX 7W
「ヘッドカバーも一緒に出品します」
「純正ヘッドカバーを付けて出品します」
```

見つかったきっかけは、**検死結果（部品検出=★単品）と本文（シャフト・長さ・
重量が明記された完品）が食い違ったのを追ったこと**。
「おかしいな」で流していたら気づかなかった。

**How to apply:**
- **検出結果と本文が食い違ったら必ず追う。** どのパターンが当たったかは
  `_HEAD_ONLY_DESC_PAT.pattern` を `|` で分割して総当たりすれば特定できる
- 完品側のテストケースを増やす。[[corpus-not-enough-for-false-positives]] のとおり
  コーパス96件では足りない
- 先読みは**狭く書くほど危ない**。`(?!カバー[付つ])` より `(?!カバー)` のように、
  取りこぼしが別パターンで拾えるなら広く書く
