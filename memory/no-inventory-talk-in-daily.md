**「今日の本命」「傾向」では、自己在庫の価格推移・値段のアドバイス・出口提案を書かない。**
ユーザーが「今出品中で、この機種の価格ってどうかな？」のように**明示的に聞いたときだけ**答える。

**Why:** 2026-09-27にユーザーから直接の指示。
「ボクの在庫の価格推移や値段の推移・アドバイスをいつもしらべてくれてありがとう。
でも今後は『今出品中で、この機種の価格ってどうかな？』みたいに聞いたときだけでいいよ！
傾向と本命のときは次からは不要で！」
日次レポートの目的は**仕入れ判断**であって、出口（自分の値付け）は別の相談事だという整理。

**How to apply:**
- 日次メモの「📦 自己在庫メモ」欄は書かない。ミニドラ欄の「自己在庫3本の相対位置」も書かない
  （CLAUDE.md の手順6・手順9から削除済み）
- `scripts/mini_report.py` は在庫セクションを出し続けるが、**聞かれない限りメモに転記しない**
- 在庫台帳 [[flip-inventory]] と `ゴルフ利益計算.xlsm` は従来どおり参照してよい。
  禁じているのは**毎日勝手に在庫の値付けを論じること**で、在庫の把握そのものではない
- 例外: 仕入れ候補が自己在庫と直接ぶつかる（自己競合になる）ときは一行だけ触れてよい

⚠ 関連の事故: 2026-09-24のメモで他人の出品（出品者「ノビ」・出品中274件）を
「自分の玉」と書いていた。**在庫の出品IDは出品者名まで確認してから自分のものと呼ぶこと**。
毎日在庫に言及する運用をやめれば、この種の誤記も減る。
