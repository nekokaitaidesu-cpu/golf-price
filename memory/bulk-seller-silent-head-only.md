**⚠ 暫定（n=13・要追試）。落とす条件には使わず、写真を見る優先度としてだけ使う。**

出品者の **出品中の件数が200件以上**なら、完品風の題名でも
**ヘッド単品を疑って先に写真のホーゼルを見る**。

**Why:** 2026-09-12、ユーザーが「名器 PING G410 ユーティリティ 4U 22°」
（m80642211578・14,000円）を見て「ナチュラルにヘッドのみなのひどすぎる」と指摘。
説明文は「ヘッドカバー付属（傷み有り）致命的なダメージ無くまだまだ使用可能です」だけで、
**打てる前提で書いてある**のにヘッド単品だった。
同種の出品に共通点が無いか調べたところ、出品者は全員別人だったが出品数で分かれた:

```
ヘッド単品と判定した8件: 中央 386件 / 200件以上が 6/8
  249(名器G410) 636(G410カバー付) 370(名機G430) 1637(SIM2 MAX)
  403(TSR2) 939(ステルス2プラス) 87(G425 MAX) 2(G425 LST)
完品と判定した5件:       中央  59件 / 200件以上が 0/5
  20(スパイダーGT) 122(M2 FW) 154(Qi10) 25(PARADYM 7W) 59(ファントム12.5)
```

とくに**説明文が無言だった3件は全て249件以上**（名器G410 249／G410カバー付 636／
SIM2 MAX 1637）。逆に「ヘッドのみです」と明記していた2件は個人だった（出品数2・87）。
業者アカウントはテンプレ説明を使い、ヘッド単品であることを開示しない。

**How to apply:** `honmei_autopsy.py` が出品者名と出品数を表示し、200件以上に
⚠を付ける（2026-09-12 実装）。⚠が出て説明文が短ければ**必ず写真を見る**。
判定そのものは [[silent-head-only-price-ratio]]（価格比0.9〜1.1）と
写真のホーゼル目視（[[honmei-genbutsu-check]]）で行う。
[[head-only-seller-fingerprints]] の「名器！」「名機」も引き続き有効で、
今日の2件（名器G410・名機SIM2 MAX）は両方ヘッド単品だった。
[[headcover-not-proof-of-complete]] も同じ個体で再確認している。
**サンプルが増えたらこのメモの数字を更新すること。**
