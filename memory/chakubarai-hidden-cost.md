**着払い（📦）の出品は、受け取り時に自分が送料を払う。**
候補リストの割安率も粗利計算もこれを含んでいないので、**手で足してから判定する**。

```
実質仕入 = 表示価格 + 着払い送料（ドライバー/FW 約1,200・アイアン/ウェッジ 約1,100）
1.30倍判定 = 想定売値 ÷ (実質仕入 + 再出品の送料)
```

**Why:** 2026-10-04、ボーケイ SM10 54° 14F が **9,300円（割安率66%）** で候補の最上位に出た。
完品・溝残り・写真15枚・7日実売6本と条件は良かったが **📦着払い**。
```
実質仕入 9,300 + 着払い1,100 = 10,400
13,995 ÷ (10,400 + 1,450) = 1.18倍 ・ 粗利 +746  → 見送り
```
送料を無視すると買ってしまう水準だった。

**How to apply:**
- 候補リストの `📦着払い` 印を見たら、**その場で送料を足した割安率に読み替える**
- 目安として、着払いは**割安率を5〜10ポイント押し上げて見せている**（9,300/13,995=66% →
  実質10,400/13,995=74%）
- 安い玉ほど送料の比重が大きいので、**1万円以下の着払いは特に効く**
